# URL Shortener Web App with Click Analytics Dashboard 

- Designed Using Laravel, React, Inertia.js and Tailwind CSS.

---

### Welcome to my first goal-driven Laravel Project!

---


### Some details:

- First proper goal-driven Laravel + React + Inertia.js + Tailwind CSS project with pre-determined objectives by me
- This project will be utilised as a learning experience to how to build end-to-end Laravel + Vue.js projects

- Initial Objectives:
	- Nice frontend UI design
	- Click Analytics Dashboard
	- Basic Security and Authentication Practices
	- Production Ready setup with Docker containerisation (Ready for scaling)
- AI feature integration will be considered during later stages of development (MCP Servers, RAG, LLMs, Chatbots, etc).

---

### Design Architecture

- This web application is designed based on a Code-First Design Approach. The API documentation is designed after the codebase is nearing completion. 
- This approach was chosen to provide flexibility to this project, as it is exploratory and focused on providing a good learning experience.


### **Regarding AI Use**:

- This web app promises to use **ZERO AI generated code**. From the first commit onwards. This remark will be left in this README.md file as a testament to this promise.
- AI assistance (non-code based) will be heavily limited. Whenever documentation is available, it will be chosen over AI guidance. AI assistance will only be treated as a **LAST** resort for problem solving if a bottleneck burns too much time.
